Описание проекта

В этом проекте вы создадите приложение для учета личных финансов, в котором можно фиксировать доходы и расходы,
планировать бюджет на месяц и смотреть отчеты по категориям.

Вы научитесь работать с финансовыми данными, строить агрегированные отчеты за период и делать удобный интерфейс для
ежедневного учета.
Требования:

Необходимо реализовать базовый учет финансов. Для этого требуется:

- добавить операции доходов и расходов с фильтрацией по дате, категории и типу;
- сделать месячные бюджеты и расчет прогресса по ним (потрачено и остаток);
- реализовать отчеты за период: суммы по категориям и динамика по дням.

Отдельно продумайте хранение денежных значений без ошибок округления.

```txt
POST /transactions                              # Добавление операции
GET /transactions?from=&to=&category_id=&type= # Получение списка операций с фильтрами
PUT /transactions/{transaction_id}           # Редактирование операции
POST /budgets                                 # Добавление бюджета
GET /budgets/current                          # Получение текущих бюджетов
GET /reports/categories?from=&to=            # Отчет по категориям за период
GET /reports/timeseries?from=&to=&interval=day # Отчет по дням за период
```
